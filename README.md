# BookMyJourney — Travel Planning SaaS Landing Page

BookMyJourney is a modern, responsive travel-planning website designed to help users discover destinations, organize trips, manage travel budgets, and explore travel-planning features through a clean and intuitive interface.

## Live Demo

**Website:** https://bookmyjourney-travel.netlify.app/

## Features

- **Responsive Navigation:** Easy navigation with a mobile-friendly menu.
- **Hero Section:** Modern landing page with travel-focused messaging and calls to action.
- **Destination Discovery:** Explore popular travel destinations.
- **Trip Planner:** Interactive trip-planning interface.
- **Travel Features:** Discover places, plan itineraries, manage budgets, and stay organized.
- **Pricing Plans:** Explorer Free and Adventurer plans with monthly and yearly pricing options.
- **Pricing Comparison:** Compare the features available in different plans.
- **FAQ Section:** Answers to common questions.
- **Contact Form:** Client-side form validation and submission success feedback.
- **Responsive Design:** Designed for desktop, tablet, and mobile screens.

## Installation and Setup

### 1. Clone the repository

```bash
https://github.com/Asr1403/BookMyJourney
```

### 2. Navigate to the project folder

```bash
cd trippilot-landing
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal, usually:

```text
http://localhost:5173
```

## Production Build

To generate the production-ready build:

```bash
npm run build
```

The production files will be generated inside the `dist` directory.

## Deployment

The website is deployed using Netlify.

**Live URL:** https://bookmyjourney-travel.netlify.app/

## Design Approach

BookMyJourney uses a premium dark navy and purple visual theme to create a modern travel SaaS experience. The interface uses clear sections, consistent spacing, attractive destination imagery, and responsive layouts to make navigation simple and engaging.

This project is a front-end demonstration. The contact form currently provides client-side validation and success feedback; it does not send or store enquiries. Pricing plans are displayed for demonstration and do not process payments.
